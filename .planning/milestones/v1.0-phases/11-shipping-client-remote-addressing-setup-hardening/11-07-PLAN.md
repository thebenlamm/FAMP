<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local agent -> bus Send (`from` field) | a registered agent authors the envelope `from`; the broker authenticates the connection but (today) does not bind `from` to it |
| bus (unsigned) -> gateway egress (Ed25519 sign) | the gateway signs the caller-supplied `from` as its own domain — must not sign for a domain it does not own |
| gateway process init -> "ready" health signal | a premature ready line masks an unloaded keyring (false success) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-18 | Spoofing | envelope `from` unbound from authenticated identity (broker) | high | mitigate | Broker gates `from.name() == effective_identity` before insertion; forged `from` rejected typed (Task 1) |
| T-11-19 | Spoofing / Tampering | gateway signs `from` for a domain it doesn't own (egress) | high | mitigate | Egress rejects `from.authority() != own-domain` when configured, before `sign_federation_fields` (Task 2) |
| T-11-20 | Spoofing / DoS-on-self | own-domain drift makes gateway sign a label the peer didn't pin | high | mitigate | Own-domain single-sourced (plan 02) + egress assertion converts remote `UnpinnedKey` into a loud local error |
| T-11-21 | Repudiation | "ready" printed before keyring load (false success) | medium | mitigate | Ready line moved after full init; process-readiness test (Task 2) |
| T-11-22 | Spoofing | own-domain-UNSET egress signs `from` verbatim (residual) | low | accept | Documented known-limitation: enforcement is when-configured; UAT-01 configures own-domain on both hosts, closing it operationally. No cross-person trust at v1.0 (own two machines). Full structural enforcement tracked for v1.1. |

No new dependencies — no supply-chain (T-*-SC) row.
