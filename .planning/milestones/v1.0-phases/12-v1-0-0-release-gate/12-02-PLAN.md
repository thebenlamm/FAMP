## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| remote gateway → local ingress | Untrusted signed bytes arrive over HTTPS at `ingress.rs::inbox_handler` and must be verified, domain-checked, and destination-checked before any mailbox write. |
| local bus → gateway egress | A locally-authenticated agent's envelope reaches `egress.rs::relay_one` and is signed under this host's key — the point at which local trust becomes cross-host assertion. |
| local agent → broker | `handle.rs::send` binds the envelope `from` leaf-name to the connection's authenticated identity. |
| operator config → route map | `main.rs::build_route_map` turns operator-declared `--backs`/`--peer` bindings into routing authority. |
