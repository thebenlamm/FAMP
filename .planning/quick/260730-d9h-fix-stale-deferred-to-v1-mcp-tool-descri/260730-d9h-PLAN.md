<objective>
Fix three factually false strings in the FAMP MCP tool registry that name a version
which has already shipped, and delete two chronically flaky tests that drive a frozen
archived shell script.

Purpose: v1.0.0 was tagged 2026-07-29 at `5edff41` WITHOUT broker-side terminal-FSM
filtering, so every "deferred to v1" string now names a version that came and went.

unshipped filter ("unlike famp_inbox list, which hides entries for tasks that have
reached a terminal FSM state") — which is false end-to-end and actively misleads any
agent reading the tool registry. Separately, two tests in
`famp_local_wire_migration.rs` can only ever fail for environmental reasons and never
for a real regression, because CI `paths-ignore` excludes `docs/**` — the script they
exercise cannot trigger a CI run.

Output: two atomic commits, an installed binary proven to serve the corrected text,
and one surviving zero-flake static test.
</objective>
