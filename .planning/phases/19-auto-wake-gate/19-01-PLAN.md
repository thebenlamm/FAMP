<interfaces>
Existing contracts to preserve:
- `Origin::{Local, Gateway, Unknown}`; absence and invalid provenance resolve to `Unknown`.
- `DrainPolicy { filter, skip_self_authored, cap }` has exactly three construction sites: Await, channel Inbox, and shared Register/Join/agent-Inbox decode.
- `waiting_clients_for_name(broker, name, envelope) -> Vec<ClientId>` selects live canonical/proxy waiters and currently checks only task matching.
- `client_origin(broker, sender) -> Origin` is proxy-aware and is the only authority for the sender origin.
- `Out::AppendMailbox { target, line, origin }` is staged before Await replies; the production executor applies `famp_bus::stamp_line(line, origin)` before disk append.
- Agent Inbox uses caller `since`; channel Inbox uses `inbox_offsets`; Await uses `await_offsets`. These cursor authorities remain independent.
</interfaces>
