## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] dist 0.32's config lives in `dist-workspace.toml`, not `Cargo.toml`**
- **Found during:** Task 1, Step 2 (`dist init`)
- **Issue:** The plan's acceptance criteria and must-haves assumed `[workspace.metadata.dist]` in the root `Cargo.toml`. Running `dist init` with the pinned 0.32.0 binary wrote a separate `dist-workspace.toml` at the workspace root instead, plus a `[profile.dist]` build-profile block in `Cargo.toml` (a legitimate companion dist itself requires, not per-crate metadata).
- **Fix:** Proceeded with `dist-workspace.toml` as the single canonical config location, matching what the actually-installed pinned tool version does. Re-verified every acceptance-criteria invariant (`cargo-dist-version`, `ci`, `installers`, `checksum`, `install-path`, `targets`, no `aarch64-unknown-linux`, no windows target, no per-crate `metadata.dist`) against `dist-workspace.toml` instead of `Cargo.toml`.
- **Files modified:** `dist-workspace.toml` (new), `Cargo.toml` (`[profile.dist]` only)
- **Verification:** `grep -rln 'metadata.dist' crates/*/Cargo.toml` returns nothing; `dist plan`/`dist generate`/`cargo metadata --no-deps` all succeed; CI green on the shipping SHA.
- **Committed in:** `85d6e0e` (Task 1 commit)

**2. [Rule 2 - Missing critical] Runner override needed to make D-08a's intent actually true in the generated CI**
- **Found during:** Task 2, before regenerating `release.yml`
- **Issue:** `dist plan`'s own `artifacts_matrix` output showed dist's built-in default assigns `x86_64-apple-darwin` to `macos-15-intel` (a runner class GitHub has published a sunset date for) and `aarch64-apple-darwin` to `macos-14` — two separate native runners, exactly the outcome D-08a's resolution was meant to retire, even though the cross-build itself is proven clean.
- **Fix:** Added `[dist.github-custom-runners]` pinning `x86_64-apple-darwin = "macos-14"` (same runner as the aarch64 target, forcing cross-compilation) and `x86_64-unknown-linux-gnu = "ubuntu-22.04"` (explicit pin per D-04). Regenerated and confirmed via `dist plan` that both darwin targets now resolve to `macos-14`.
- **Files modified:** `dist-workspace.toml`, `.github/workflows/release.yml` (regenerated)
- **Verification:** `dist plan --tag=v1.0.0 --output-format=json` shows `aarch64-apple-darwin -> macos-14` and `x86_64-apple-darwin -> macos-14`, both with no `container` override; `x86_64-unknown-linux-gnu -> ubuntu-22.04`.
- **Committed in:** `efc92b2` (Task 2 commit)
