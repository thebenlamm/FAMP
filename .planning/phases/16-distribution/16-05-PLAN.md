    milestone's actual release.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Repo history -> public Release | A pushed tag converts local history into publicly downloadable executables; there is no review step after it. |
| Published installer -> a stranger's machine | The curl command in the docs is executed by people who did not read the installer. |
| CI container -> the DIST-02 claim | A container is a proxy for "no Rust toolchain", and can be mistaken for a proxy for "fresh machine". |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-16-13 | Tampering | A tag cut from unpushed or unverified local history | high | mitigate | Task 2's precondition asserts `git rev-list --left-right --count origin/main...HEAD` is zero-ahead, and Task 4 tags only a SHA whose check-runs were verified green. |
| T-16-14 | Repudiation | A release run reported green while a job was skipped or softened | high | mitigate | Task 4 verifies by ASSET LIST and by the `install-gate` log excerpt, not by a job name; an acceptance criterion forbids `--no-verify` and `continue-on-error`. |
| T-16-15 | Spoofing | The container gate being read as satisfying DOC-07, so Phase 20 skips real fresh-machine validation | high | mitigate | The workflow header, `docs/DISTRIBUTION.md`, and a prohibition all state the bound explicitly; the human-verify checkpoint covers the macOS leg CI structurally cannot. |
| T-16-04 | Elevation of Privilege | Installer writing outside a user-writable directory on a real macOS box | medium | mitigate | The human-verify checkpoint confirms `which famp` resolves inside `~/.cargo/bin` and that no privilege prompt appeared. |
| T-16-02 | Tampering, Spoofing | Compromised release host substituting archive and checksum together | high | accept | Unchanged from 16-01: out of DIST-03's scope per D-06, stated honestly in the docs, signing recorded as a named follow-up. |
