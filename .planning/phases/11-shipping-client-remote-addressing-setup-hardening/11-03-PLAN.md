<objective>
D-01/D-02/D-03/D-04 / ADDR-01+ADDR-02 — the core addressing fix. Make `build_envelope_value` (`send/mod.rs` ~L413) conditional: when `--to` parses as a `Principal` (`agent:<domain>/<name>`), take the remote path — envelope `to` = the full principal verbatim (D-01 C5 pass-through), envelope `from` = `agent:{own-domain}/{identity}` (D-02, own-domain from plan 02), class upgraded to a typed `RequestBody` `request` via sign-then-strip (D-03), while the bus routing `Target.name` stays the bare leaf so the local broker routes to the gateway's proxy mailbox (split-addressing, Pattern 1). When `--to` is a bare name, keep today's local path verbatim (D-04). This is the single chokepoint covering CLI, slash, and the `famp_send` MCP tool.

Purpose: let a real shipping client — not the throwaway injector — address a remote principal and produce the exact envelope shape the gateway already relays.
Output: the conditional remote path + `--domain` flag + full unit coverage; the fixed binary installed for the MCP path.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI sender -> envelope provenance | the sender authors `from`/`to`; the receiver verifies on `from` |
| local bus (unsigned) -> gateway egress (signed) | BUS-11: crypto transition only at the gateway boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-06 | Spoofing | envelope `from` authored by sender | high | mitigate | `from` = `agent:{own_domain}/{id}`, own_domain single-sourced+validated (plan 02); receiver hard-rejects unpinned (`verify.rs`) |
| T-11-07 | Elevation of Privilege | class upgrade leaking to local chat | medium | mitigate | D-04 gate: only the domain-qualified (remote) branch upgrades to `request`; bare-name stays `audit_log` (regression-tested byte-exact) |
| T-11-08 | Tampering | signature present on the bus (BUS-11 break) | high | mitigate | sign-then-strip removes the `signature` key; unit test asserts no `signature` on the remote Value |
| T-11-09 | Repudiation | routing miss on full-principal bus Target | medium | mitigate | bus Target = leaf; test asserts Target.name never carries `agent:...` |

No new dependencies — no supply-chain (T-*-SC) row.
</threat_model>
