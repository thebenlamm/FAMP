## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI sender -> envelope provenance | the sender authors `from`/`to`; the receiver verifies on `from` |
| local bus (unsigned) -> gateway egress (signed) | BUS-11: crypto transition only at the gateway boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-06 | Spoofing | envelope `from` authored by sender | high | mitigate | `from` = `agent:{own_domain}/{id}`, own_domain single-sourced+validated (plan 02); receiver hard-rejects unpinned (`verify.rs`) |
| T-11-07 | Elevation of Privilege | class upgrade leaking to local chat | medium | mitigate | D-04 gate: only the domain-qualified (remote) branch upgrades to `request`; bare-name stays `audit_log` (regression-tested byte-exact) |
| T-11-08 | Tampering | signature present on the bus (BUS-11 break) | high | mitigate | sign-then-strip removes the `signature` key; unit test asserts no `signature` on the remote Value |
| T-11-09 | Repudiation | routing miss on full-principal bus Target | medium | mitigate | bus Target = leaf; test asserts Target.name never carries `agent:...` |

No new dependencies — no supply-chain (T-*-SC) row.
