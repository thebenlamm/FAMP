<objective>
D-06 / OBS-01: un-swallow the transport error chain so every subsequent two-machine debug in this phase surfaces a one-line diagnosis instead of the opaque "reqwest failure" string. Sequence FIRST — this is the cheapest fix on the phase list and the force-multiplier on every cross-host fault the rest of Phase 11 will hit (Gate A findings #5/#6/#8 each cost a full round-trip ONLY because the log said "reqwest failure").

Purpose: make TLS/connect/status faults self-describing at the egress log.
Output: transport-http error Display that carries its `#[source]`, an egress log that captures the full chain, and a regression unit test.

Note: the egress `from.authority() == own-domain` trust check and the gateway own-domain wiring live in Plan 07 (wave 2, depends on this plan's egress.rs edits) — NOT here. This plan is scoped to the error-chain only, kept lean because it is sequenced first as a force-multiplier.
</objective>
