<objective>
Build the inbound half of the cross-host relay: a gateway-owned axum + rustls listener that verifies each POSTed envelope against the gateway's pinned peers keyring, then delivers the verified bytes onto the local bus via the backed sender stand-in — so the local broker advances the task FSM exactly as if the sender were local.

Per D-04 and 09-RESEARCH §3, `famp_transport_http::build_router()` cannot be reused: it unconditionally mounts `FampSigVerifyLayer` against its own keyring, which would create a second trust source (the exact split-authority failure Phase 8 D-08 rejects). This plan hand-assembles a parallel router (Option A) reusing only the route constant + body-limit layer, and puts `verify_inbound_any` inside the handler as the sole trust decision.

Purpose: Make "a signed POST arrives at B's gateway" become "delivered into bob's real local mailbox, or a loud 4xx with zero writes."
Output: `ingress.rs` with the router, handler, and TLS server task.
</objective>
